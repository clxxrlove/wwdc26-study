# Prompt 00 — Bootstrap Codex

너는 지금부터 이 레포의 WWDC26 리서치 하네스 담당자다.

목표는 WWDC26 전체 영상을 다 요약하는 것이 아니라, 모바일 앱 보안 솔루션 / Xcode Toolchain / Swift Compiler / LLVM Pass 관점에서 필요한 내용만 선별해서 스터디용 브리프를 만드는 것이다.

스터디 관점:

- 모바일 앱 보안 솔루션 개발
- 대상 보안 도구는 Xcode/build pipeline 통합 형태일 수 있음
- 컴파일 또는 빌드 단계에서 보안 로직을 적용하는 솔루션일 수 있음
- 실제 구현은 LLVM Pass, Swift/iOS 앱 구조, Xcode toolchain, 앱 난독화/무결성/anti-tamper와 관련될 수 있음

먼저 다음 파일을 읽어라.

- AGENTS.md
- README.md
- docs/study-context.md
- docs/priority-rubric.md
- registry/seed_sessions.csv
- outputs/watch-priority.md

그 다음 다음 작업을 수행하라.

1. 이 레포의 목적을 5줄로 재정의하라.
2. `registry/seed_sessions.csv`의 세션을 A/B/C/Skip으로 다시 검토하라.
3. `outputs/watch-priority.md`를 갱신할 계획을 세워라.
4. 우선 A 세션부터 `sessions/notes/`에 세션 노트를 만들 작업 순서를 제안하라.
5. 절대 모든 세션을 동일한 깊이로 요약하지 마라.
6. 불확실한 내용은 “확인 필요”라고 표시하라.

응답은 한국어로 하고, 실행 가능한 작업 계획으로 작성하라.
