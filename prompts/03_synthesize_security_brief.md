# Prompt 03 — Synthesize Security Brief

`sessions/notes/`에 있는 세션 노트를 종합해서 `outputs/wwdc26-security-brief.md`를 완성해라.

목표:

스스로 이해하고 반복해서 업데이트할 수 있는 3~5페이지 분량의 학습 브리프를 만든다. 이 문서는 “WWDC26 전체 요약”이 아니다. 목적은 “모바일 앱 보안 솔루션 / Xcode Toolchain / Swift Compiler / LLVM Pass 관점에서 무엇을 이해했고, 무엇을 아직 확인해야 하는지”를 정리하는 것이다.

구성:

1. Scope
2. Executive summary — 5개 bullet
3. Xcode / Toolchain implications
4. Swift / Compiler implications
5. iOS Security implications
6. App Attest / Trust Insights가 mobile app protection/toolchain integration 관점에서의 의미
7. Security/toolchain impact hypotheses
8. Risks / unknowns
9. Sessions reviewed
10. What I should personally watch
11. Follow-up questions

작성 규칙:

- 너무 길게 쓰지 말고, 개인 스터디 노트처럼 작성
- “이해한 것”과 “후속 확인이 필요한 것”을 분리
- 구현 구조를 단정하지 말고 “추정”, “확인 필요”라고 표시
- 세션별 요약을 복붙하지 말고, 주제별로 재구성
- 직접 영상을 보는 것이 좋은 세션과 transcript/요약으로 충분한 세션을 구분
- 직접 영상 권장 세션도 반드시 요약본은 제공
