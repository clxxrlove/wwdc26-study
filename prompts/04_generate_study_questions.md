# Prompt 04 — Generate Study Questions

`sessions/notes/`와 `outputs/wwdc26-security-brief.md`를 바탕으로 `outputs/study-questions.md`를 갱신해라.

목표:

후속 학습 질문을 만들되, 질문은 단정적이거나 아는 척하는 톤을 피한다. 목적은 WWDC26 학습 내용을 실제 toolchain/security 맥락과 연결하기 위한 학습 방향 확인이다.

질문 카테고리:

1. Integration context
2. Xcode / Build pipeline
3. Swift / LLVM / Compiler
4. iOS app security
5. App Attest / Apple security frameworks
6. Target-app compatibility
7. Testing / diagnostics / CI
8. Study plan

작성 규칙:

- 질문은 한국어로 작성
- 각 질문 아래에 “왜 묻는가”를 1줄로 붙임
- 질문은 너무 단정적이지 않게 작성
- 비공개 정보를 요구하는 느낌의 질문은 피하고, 학습 방향을 확인하는 질문으로 표현
